# OpenAPI schemas

The official JSON Schemas of the OpenAPI Specification, used to check documents in the OpenAPI editor:

- `openapi-3.0.json`: https://spec.openapis.org/oas/3.0/schema/2024-10-18
- `openapi-3.1.json`: https://spec.openapis.org/oas/3.1/schema/2022-10-07
